## Product thesis

디자인 감각을 바탕으로 사용자 접점 제품을 0→1로 만들고, AI UX·상태 관리·운영 안정성까지 연결하는 프론트엔드 개발자의 공개 증거 허브.

## 0.1.0 scope

- Home / About
- Selected Personal Work: Bookgolas, 바로구니, byungskerlog
- Experience: 모빌리티 UX 웹앱 기반 키오스크
- Labs: JSON Animation Viewer and selected npm/open-source work
- Responsive, accessible, linkable project detail pages
- SEO and social metadata

## Explicit exclusions

No company source code, private screenshots, customer details, internal URLs,
unpublished metrics, credentials, CMS, authentication, comments, newsletter,
or analytics dashboard in the first release.

## Project page contract

Each project page contains: Context, Problem, Role, Build, Outcome, Limits, and
Links. Planned work and shipped work must be visibly separated.

## Release gate

The release is ready only when the three personal products are publicly linked,
the company-project disclosure review passes, mobile and keyboard flows are
verified, and lint, typecheck, build, link, content, and browser smoke checks
pass.
